# 本地表情库

回复工作台提供“纯文字”“自然搭配”“优先表情”。自然搭配只在语境合适时选图，优先表情允许单独用图片回应。每条候选最多一张图，可换图或取消搭配，文字和图片分别复制，用户自行粘贴并发送。

“表情库”页支持批量导入 PNG、JPG、静态 WebP，搜索、编辑名称/标签/适用及避免场景、删除、复制图片。图片上限 8 MB、最长边 2048，导入后转换成 PNG 并以内容哈希去重。新导入图片默认不参与推荐，填写标签后才能启用。亲密素材需要本轮单独勾选允许。

素材位于当前数据根目录的 `data/stickers/`，`index.json` 保存元数据，`<id>.png` 保存实际图片。源码版直接使用项目目录；安装版使用 `%LOCALAPPDATA%/ChatJunshi/data/stickers/`。个人素材不进入 Git，也不随安装器分发。源码个人库可通过安装版“导入图片”选择 PNG，之后重新填写标签；本版不提供整库迁移。

## 推荐与校验

Go 从已启用且文件存在的素材中排除本轮不允许的亲密图片，提供全部符合本轮设置的精简目录，不做关键词截断。目录以 S001 等本轮短编号表示，只包含名称、标签、适用及避免场景和亲密标记；短编号由宿主映射回本地文件 ID。模型先考虑自己生成的候选回复，再按语义选图。模型在原有一次调用中返回 `sticker_id`、`sticker_reason`、`send_order`，Codex 与三种自定义 API 协议使用相同结构。模型接收名称、标签、使用说明和 ID，不上传素材图片；标签描述依赖人工核对。

发送顺序为 `none`、`text_first`、`image_first` 或 `image_only`。无图时 ID 为空；本轮有素材却不选图时，必须说明没有匹配素材或语境更适合文字的具体原因，并在候选卡展示。纯文字模式或空目录时理由可为空。只有图片时正文为空。宿主只接受本轮实际提供的 ID，并加载本机预览，拒绝编造 ID、越界选择和缺失文件。切换会话、修改输入或表情库后，旧建议失效。模型流式预览只展示文字，完整校验后才显示可复制的配图。

Windows 图片复制使用 CF_DIB 静态位图，透明区域铺为白色。GIF 原文件可以保留在个人库的 `originals/`，当前推荐与复制使用人工核对过的静态帧。真实微信版本的粘贴显示效果需在用户环境验证，不保证动图发送。

## 素材来源与授权

个人图片及来源记录由用户保存在本机，不纳入仓库或安装包。建议逐张记录来源和授权状态；公开可访问的图片不代表允许再分发，未确认授权的素材仅留在个人库。项目 MIT 许可证不授予第三方图片的使用或分发权利。

`packaging/prepare-personal-stickers.py` 可根据本机 `data/stickers/sources.json` 中的 `file`、`series`、`source`、`license` 字段生成静态帧和总览图，重复运行保留已编辑元数据。`packaging/refine-personal-sticker-tags.py` 可补充常见场景标签，运行后仍需人工核对。两者仅操作本机素材，不下载图片，也不提供素材授权；准备静态帧需要 Pillow，它不是生产运行依赖。

## 验证

Go 测试覆盖导入去重、元数据保存、推荐启用条件、动画 WebP/无效图片拒绝、路径越界拒绝、删除、亲密过滤、完整目录超过 40 张不截断、短编号映射、不选图理由、输出结构与本轮 ID 校验。前端虚构预览覆盖图片卡片、搜索、编辑表单、换图与取消搭配。

运行项目 Go 测试与前端生产构建后再构建 Wails。静态/模拟验证不证明真实模型选图质量或微信端粘贴效果。
